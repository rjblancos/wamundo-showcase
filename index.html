By day and time, with staggering between recipients and load sharing across lines.

Cómo está construido

How it is built

Panel web y API→Servicio de mensajería en 20 instancias→Red de mensajería·App pasarela SMS·App de chat
Web dashboard and API→Messaging service on 20 instances→Messaging network·SMS gateway app·Chat app

El panel no tiene estado; las sesiones, que deben vivir de forma continua, las mantiene un servicio aparte en Go.

The dashboard is stateless; sessions, which must stay alive continuously, are kept by a separate service written in Go.

Garantías técnicas

Technical guarantees

SesionesSessionsSe recuperan solas al arrancar, y revincular crea una sesión nueva sin cortar la que funciona.They recover on their own at startup, and re-linking creates a new session without cutting the working one.
ReiniciosRestartsUna instancia que se apaga devuelve a la cola lo que no empezó: ningún envío se pierde.An instance shutting down returns unstarted work to the queue: no send is lost.
SeguridadSecurityProtección CSRF, API por clave, puente de soporte firmado con HMAC y caché cifrada en la app.CSRF protection, key-based API, HMAC-signed support bridge and an encrypted cache in the app.
CalidadQualityPruebas automáticas del servicio de mensajería: identidad, eventos, notas de voz, cola y revinculación.Automated tests for the messaging service: identity, events, voice notes, queue and re-linking.
